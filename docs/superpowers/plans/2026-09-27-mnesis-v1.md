# Mnesis V1 — Plan d’implémentation

> **Pour les agents d’implémentation :** SOUS-SKILL OBLIGATOIRE : utiliser `superpowers:subagent-driven-development` (recommandé) ou `superpowers:executing-plans` pour exécuter ce plan tâche par tâche. Les étapes utilisent la syntaxe de cases à cocher (`- [ ]`) pour le suivi.

**Objectif :** livrer une première version verticale de Mnesis capable de converser simplement en français sans LLM, de persister son état, de distinguer mots et concepts, d’apprendre un mot depuis une source lexicale, de gérer confiance et contradiction, et d’être utilisable via une interface Web sobre.

**Architecture :** un cœur Python indépendant des interfaces expose des services cognitifs testables. PostgreSQL conserve l’état durable ; FastAPI expose le moteur ; un paquet versionné `core-fr` fournit le socle linguistique initial ; une application Web TypeScript/React consomme uniquement l’API. Les frontières entre moteur, persistance, API, sources externes et interface doivent rester explicites.

**Pile technique :** Python 3.13+, FastAPI, Pydantic v2, SQLAlchemy 2.x, Alembic, PostgreSQL 16+, pytest, Ruff, mypy, TypeScript, React, Vite, Vitest, Testing Library.

**Spécification :** `docs/superpowers/specs/2026-09-27-mnesis-cognitive-agent-design.md`

## Contraintes globales

- Aucun LLM ne doit être utilisé pour comprendre, raisonner ou générer les réponses.
- Le moteur cognitif doit rester indépendant de FastAPI et de l’interface Web.
- Les mots et les concepts doivent être représentés séparément.
- Chaque connaissance acquise doit conserver sa provenance et son niveau de confiance.
- Une affirmation utilisateur ne doit jamais écraser silencieusement une connaissance existante contradictoire.
- Les instances Mnesis doivent être isolées par défaut.
- Le paquet `core-fr` doit rester séparé du moteur et versionné.
- Une capacité doit être identifiable comme native, apportée par `core-fr` ou apprise ensuite.
- La V1 est textuelle uniquement.
- L’interface Web doit rester sobre, sans codes visuels d’assistant IA générative.
- La documentation du projet est rédigée en français.
- Le développement suit TDD : test en échec, implémentation minimale, test vert, puis commit.

## Points de vigilance pour la revue

1. **Entrée utilisateur vide ou uniquement composée d’espaces** : l’API doit répondre par une erreur métier claire sans créer de souvenir ou de message vide.
2. **Deux instances portent des états différents** : une conversation ou un apprentissage sur l’instance A ne doit jamais être visible depuis B.
3. **Une affirmation utilisateur contredit une connaissance fiable de `core-fr`** : Mnesis doit préserver les deux éléments de preuve et produire un état de conflit, sans écrasement.
4. **Une source lexicale renvoie une définition invalide ou indisponible** : l’échec d’apprentissage doit rester explicite et ne pas créer de connaissance artificielle.
5. **Un mot est connu lexicalement mais son concept est insuffisamment maîtrisé** : Mnesis ne doit pas le traiter comme une connaissance fiable uniquement parce que le lexème existe.

## Hors de ce plan

Ces éléments sont prévus par la spécification mais feront l’objet de plans distincts après validation de la V1 :

- recherche Web autonome multi-source réelle ;
- notation avancée de fiabilité des sources ;
- apprentissage récursif profond depuis dictionnaires ;
- consolidation et oubli avancés ;
- propagation d’activation associative ;
- apprentissage de nouvelles constructions grammaticales à grande échelle ;
- langage procédural apprenable ;
- apprentissage du comptage à partir des primitives ;
- généralisation de procédures ;
- export et promotion d’apprentissages locaux vers de nouveaux paquets de connaissances ;
- intégration X/Twitter et autres canaux ;
- déploiement public multi-instance ;
- authentification et administration.

## Critère de sortie de la V1

La V1 est considérée comme atteinte lorsqu’une instance fraîche, après déploiement explicite de `core-fr`, peut tenir un échange français simple, apprendre un mot absent de son socle depuis une source lexicale, réutiliser cet apprentissage plus tard, exprimer un doute face à des preuves contradictoires, conserver mémoire et provenance, et exposer le tout via une interface Web sobre et une trace cognitive inspectable — sans aucun LLM.
